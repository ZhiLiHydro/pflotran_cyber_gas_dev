# ML fracture-surrogate regression tests

## Fast tests (in `make test`): single-cell decks certified by an independent oracle

`ml0d_<model>.in` is a one-cell fracture (material ID 3), no minerals, no transport, a fixed
alkaline water (pH 12.735 with OH- as the only complex gives Total H+ = -0.0550, the live
inlet-cell value of katdiss run.1; Ca 1.65e-2, Si 2.47e-5, Al 5.17e-4, Mg 3.4e-10), ten 10-y
steps.  The surrogate's five inputs are therefore constant and its whole trajectory can be
recomputed from the weight file alone: `ml_surrogate_oracle.py` (numpy + h5py, no torch, no
PFLOTRAN code) re-implements the documented contract — clip/log10/standardize, 3 ReLU layers,
the sinh output stage (stage 0) or the node_min_v1 bounded stage with the pore-volume budget
and Ca/Si clamp (stage 1), the host update, and permeability = k0 (phi/phi0)^3 — and compares
it with the run's `.regression` file and with the per-step DIAGNOSTIC_FILE dump (every input the
surrogate saw, every rate and state it produced).  Agreement is ~1e-14; tolerance 1e-9 relative
with a 1e-10 absolute floor.  Each deck runs in ~0.1 s.

| test | weight file | output stage |
|---|---|---|
| ml0d_bthuber | bthuber_weights.h5 | 0 (sinh rate; the deployed July 2026 MLP) |
| ml0d_node_phi | node_phi_weights.h5 | 0 (neural-ODE phi, drop-in) |
| ml0d_node_min_lin | node_min_lin_weights.h5 | 1 (node_min_v1, linear ramp; recommended) |
| ml0d_node_min | node_min_weights.h5 | 1 (node_min_v1, smoothstep2 ramp) |

How the gold files are known to be correct: `python ml_surrogate_oracle.py --gold ml0d_*.in`
recomputes each committed `.regression.gold` from the weight file (the diagnostic dump of a run
is needed for the per-step check; `-e <pflotran>` runs the deck first).  Regenerate gold files
with `regression_tests.py --update` only when a changed result is intended, and re-certify.

Run:
* `make ml_surrogate` (from regression_tests/) or `make test` — gold-file comparison of the 0-D decks
* `make test_ml_surrogate` (from src/pflotran/) — forward-pass golden vectors of every weight file,
  then the 0-D oracle against the built `pflotran`
* `python -m pytest node_development/tests` (ML repo) — includes the 0-D oracle when the binary exists

## Slow integration tests (on demand): `make ml_surrogate_1d`

`ml_<model>.in` are the katdiss run.1 decks (29x1x4 cells, full chemistry, cement liner, RegI
inlet) shortened to 300 y, ~15 s each; the REGRESSION block records porosity and permeability of
fracture cells 91..116.  Their gold files are self-consistency references (generated by the
`heeho/ml-node-min` binary), not independently certified.

The weight files and test vectors are copies of `node_development/export/` and
`chuber_handoff/` in the ML repository; regenerate them there (export_node.py) and copy.
